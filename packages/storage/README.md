# @teamblind/axeda-storage

Object storage for the images of [Axeda](https://github.com/teamblindmx/axeda) (logos, favicons and profile pictures): Cloudflare R2, Amazon S3, MinIO and other S3-compatible stores. It signs requests with AWS Signature Version 4 on WebCrypto, so it does not need the AWS SDK.

> **Status:** alpha; the API can still change before 1.0. Documentation: [English](https://github.com/teamblindmx/axeda/tree/main/docs/en) · [Español](https://github.com/teamblindmx/axeda/tree/main/docs/es).

Part of [Axeda](https://github.com/teamblindmx/axeda), hierarchical authorization (global → company → business → site) on top of [Better Auth](https://www.better-auth.com). Licensed under [Apache-2.0](LICENSE).
